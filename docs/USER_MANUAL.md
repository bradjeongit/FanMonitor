## 1. 프로그램 개요

온실의 **기존 팬 모터(기존모터)** 의 회전수(RPM)를 읽어서, 같은 구역에 새로 설치한 **신규 팬 모터(신규모터)** 가 같은 RPM(또는 지정한 고정 RPM)으로 돌도록 자동 제어하고, 모든 모터의 상태를 한 화면에서 감시하는 프로그램입니다.

| 용어 | 뜻 |
|---|---|
| 구역 | 화면의 1~8구역. 1~4구역 = 온실1, 5~8구역 = 온실2 (설정 파일에는 H1R1~H1R4, H2R1~H2R4 로 저장) |
| 라인 | 구역 안의 **짝** 줄 또는 **홀** 줄. 라인마다 기존모터 통신장치 1개, 신규모터 통신장치 1개가 연결됨 |
| 기존모터 | RPM 을 **읽기만** 하는 모터 (회색 팬 그림) |
| 신규모터 | RPM 을 **써넣어 제어**하는 모터 (녹색 팬 그림) |
| RPM 제어 소스 | 신규모터 목표 RPM 을 정하는 방법: **수동**(고정값) 또는 **기존모터**(지정한 기존모터의 현재 RPM 을 따라감) |

## 2. 설치와 실행

### 2.1 파이썬으로 실행
1. Windows 에 파이썬 3.9 이상을 설치합니다(python.org 설치본에는 화면 라이브러리 tkinter 가 포함되어 있습니다). 추가 패키지는 필요 없습니다.
2. 프로그램 폴더에서 실행합니다.
   ```
   python run.py
   ```
3. 옵션
   - `--config 경로` : 다른 설정 파일 사용 (기본은 프로그램 폴더의 `Config.ini`)
   - `--debug` : 통신 패킷까지 로그에 기록

### 2.2 실행파일(.exe)로 만들기
`build_exe.bat` 을 더블클릭하면 `dist\BLDC_MOTOR_MONITOR\BLDC_MOTOR_MONITOR.exe` 가 만들어집니다. 이 폴더째 현장 PC 에 복사해 사용합니다.

### 2.3 파일 위치
| 파일 | 설명 |
|---|---|
| `Config.ini` | 모든 설정(IP/PORT, 제어 소스, 모터 목록). 프로그램 폴더에 자동 생성. **기존 VB 프로그램의 Config.ini 를 그대로 복사해 써도 됩니다.** |
| `logs\motor_monitor.log` | 접속 성공/실패, 제어 시작/종료 기록 |

> 프로그램은 한 번에 하나만 실행됩니다. 이미 실행 중이면 "모니터가 이미 실행중입니다." (`MSG-MAIN-01`) 가 뜨고 새 실행은 종료됩니다.

## 4. 메인 화면 기능

### 4.1 1~4구역 제어 시작 (`MAIN-BTN-H1-START`)
1. **▶ 1~4구역 제어 시작** 을 누릅니다.
2. "1~4구역 제어를 시작하시겠습니까?" (`MSG-MAIN-02`) → **예**.
3. 1~4구역의 8개 라인이 각각 기존모터·신규모터 통신장치에 접속하고 자동 제어를 시작합니다.
4. 버튼이 **■ 1~4구역 제어 종료** 로 바뀌고, 그 구역들의 상태 점이 회색에서 파랑/빨강으로 바뀝니다.

### 4.2 1~4구역 제어 종료 (`MAIN-BTN-H1-STOP`)
1. **■ 1~4구역 제어 종료** → "1~4구역 제어를 종료하시겠습니까?" (`MSG-MAIN-03`) → **예**.
2. 모든 통신을 끊고 제어를 멈춥니다. 상태 점이 모두 회색이 됩니다.
3. 제어를 멈춰도 신규모터는 마지막으로 받은 RPM 으로 계속 돌 수 있습니다(모터 쪽 동작).

### 4.3 5~8구역 제어 시작/종료 (`MAIN-BTN-H2-START` / `-STOP`)
- 1~4구역 버튼과 같은 방식으로 5~8구역(온실2) 8개 라인을 시작/종료합니다 (`MSG-MAIN-06`, `MSG-MAIN-07`).
- 두 묶음은 서로 독립적이라 한쪽만 제어할 수도 있습니다.

### 4.4 구역 번호
- 1~4구역 = 온실1 의 1~4구역, 5~8구역 = 온실2 의 1~4구역입니다.

### 4.5 구역 패널 (`ZONE-*`)
- 짙은 남색 제목줄에 "n구역" 이 표시되고, 아래에 왼쪽 **짝** 라인, 오른쪽 **홀** 라인이 있습니다.

### 4.6 라인 패널 머리 영역 (`LINE-*`)
왼쪽 색 띠(`LINE-*-SIDE`): 주황 = 짝, 파랑 = 홀.

> 화면이 좁아 문구 끝이 잘리면 문구 위에 마우스를 올려 전체 내용을 볼 수 있습니다.

| 줄 | 표시 | 의미 |
|---|---|---|
| 1줄 | 회색 팬 그림 + 점 + `IP/PORT` | 기존모터 통신장치 주소와 접속 상태 |
| 2줄 | 녹색 팬 그림 + 점 + `IP/PORT` | 신규모터 통신장치 주소와 접속 상태 |
| 3줄 | `┖` + 점 + 문구 | 신규모터 목표 RPM 출처. `수동 > 800 RPM` 또는 `1구역 > 짝 > 5` (그 라인의 기존모터 5번을 따라감) |

**상태 점 색 의미** (5초마다 갱신)

| 색 | 1줄·2줄 | 3줄 |
|---|---|---|
| 회색 | 제어 중지 상태 | 제어 중지 상태 |
| 파랑 | 접속 정상 | 수동 모드이거나, 참조 기존모터가 '정상' |
| 빨강 | 접속 실패/끊김 (10초마다 재시도) | 참조 기존모터가 정상이 아님 → **이 라인 신규모터는 제어 보류** |

### 4.7 설정 버튼 (`LINE-*-BTN-SET`)
- 톱니 그림을 누르면 그 라인의 **라인설정 창**(5장)이 열립니다.

### 4.8 추가 버튼 (`LINE-*-BTN-ADD`)
- + 그림을 누르면 그 라인에 모터를 등록하는 **모터 추가 창**(6장)이 열립니다.

### 4.9 모터 목록 (`LINE-*-LIST`)

| 열 | 내용 |
|---|---|
| (그림) | 회색 팬 = 기존모터, 녹색 팬 = 신규모터 (마우스를 올리면 이름 표시) |
| ID | 모터 번호 |
| 상태 | 아래 표 |

| 상태 표시 | 의미 |
|---|---|
| ✔(녹색) + 숫자 | **정상** — 숫자는 현재 RPM (기존모터·신규모터 모두). 최근 60초 안에 응답을 받음 |
| ✖(빨강) + **이상**(빨강) | 60초 넘게 응답이 없음 |
| !(회색) + **중지**(연회색) | 사용 안 함으로 설정됨 (통신·제어 대상에서 제외) |
| **대기**(연회색, 그림 없음) | 등록 후 아직 응답을 받은 적 없음 |

> 신규모터도 기존모터와 같은 규칙으로 정상/이상/대기와 RPM 이 표시됩니다(v1.1.0). 신규모터의 RPM 은 모터가 보고하는 값을 다음 읽기 때 받아 표시하므로, 목표 RPM 을 써넣은 직후 몇 초 동안은 이전 값이 보일 수 있습니다.

**정렬** — 머리글을 누르면 정렬됩니다.
- 처음: 신규모터 먼저, 같은 종류는 ID 작은 순.
- (그림) 열 머리글: 종류순 / **ID**: ID 순 / **상태**: 상태순. 같은 머리글을 다시 누르면 반대 순서.

**수정/삭제** — 항목을 **더블클릭**하면 **모터 수정/삭제 창**(7장)이 열립니다.

## 5. 라인설정 창

![라인설정 창](images/dlg_line_ref_annotated.png) ![라인설정 창 - 수동](images/dlg_line_manual_annotated.png)

라인의 통신 주소와 신규모터 목표 RPM 출처를 정합니다. 제목줄을 끌어 창을 옮길 수 있습니다.

| 번호 | 항목 | 설명 |
|---|---|---|
| 2 | 위치 (`DLG-LINE-LBL-HOUSE`) | 설정 중인 라인. 예) 1구역 / 짝, 5구역 / 홀 |
| 3, 4 | 기존모터 IP/PORT (`TXT-SIP`, `TXT-SPORT`) | 기존모터 통신장치 주소. 기본 PORT 502 |
| 5, 6 | 신규모터 IP/PORT (`TXT-TIP`, `TXT-TPORT`) | 신규모터 통신장치 주소 |
| 7 | 수동 (`RB-MANUAL`) | 선택하면 13번 **수동RPM값** 칸이 나타남. 신규모터를 이 값(0~1100)으로 고정 운전 |
| 8 | 기존모터 (`RB-REF`) | 선택하면 9·10번 **참조기존모터** 칸이 나타남 |
| 9 | 참조 라인 (`CB-LINE`) | 따라갈 기존모터가 있는 라인 (1구역/짝 ~ 8구역/홀 중 선택, 다른 구역의 기존모터도 참조 가능) |
| 10 | 참조 ID (`CB-ID`) | 선택한 라인에 등록된 **기존모터** 번호 목록. 먼저 그 라인에 기존모터를 추가해야 목록에 나옵니다 |
| 11 | 저장 (`BTN-SAVE`, Enter) | 입력값을 검사한 뒤 저장하고 창을 닫음. 메인 화면 머리 영역이 바로 바뀜 |
| 12 | 취소 (`BTN-CANCEL`, Esc) | 저장하지 않고 닫음 |

**입력 규칙과 오류 메시지** (저장을 누르면 위에서부터 검사, 제목 "에러")

| 잘못된 입력 | 메시지 |
|---|---|
| IP 를 비움 | 기존모터 접속 IP를 입력해 주세요. / 신규 모터 접속 IP를 입력해 주세요. |
| IP 형식이 틀림 (예: 300.1.1.1, 1.2.3) | …접속 IP가 올바른 형식이 아닙니다.. |
| PORT 를 비움 / 숫자 아님 / 1~65535 밖 | …PORT를 입력해 주세요. / …숫자로 입력해 주세요. / …숫자로 1~65535범위로 입력해 주세요. |
| (수동) RPM 이 숫자 아님 / 0~1100 밖 | 수동 RPM속도를 숫자로 입력해주세요. / 수동 RPM속도를 0~1100범위내로 입력해주세요. |
| (기존모터) 라인 미선택 / ID 미선택 | 참조할 모터가 있는 라인을 선택해주세요. / 참조할 모터 ID를 선택해주세요. |

**참고**
- 제어 중에 IP/PORT 를 바꾸면, 현재 연결이 끊긴 뒤 다음 접속부터 새 주소를 씁니다. 바로 적용하려면 제어 종료 → 시작을 하세요.
- 수동 RPM·참조 모터 변경은 제어 중에도 다음 읽기 주기부터 바로 반영됩니다.

## 7. 모터 수정/삭제 창

![모터 수정/삭제 창](images/dlg_motor_mod_annotated.png)

목록에서 모터를 더블클릭하면 열립니다. 종류(10)와 ID(11)는 바꿀 수 없고, **사용여부**만 바꿀 수 있습니다.

| 버튼 | 동작 |
|---|---|
| 수정 (`BTN-SAVE`) | "해당 모터정보를 수정하시겠습니까?" → 예 → 사용여부 저장 |
| 삭제 (`BTN-DELETE`, 빨강) | "해당 모터정보를 삭제하시겠습니까?" → 예 → 삭제 |
| 취소 | 닫기 |

- **신규모터를 '중지' 로 바꾸면** 제어 중일 때 그 모터에 RPM 0 명령을 한 번 보내 멈춥니다.
- 다시 '사용' 으로 바꾸면 '대기' 상태에서 다시 시작합니다.
- 다른 라인이 RPM 참조로 쓰고 있는 **기존모터는 삭제할 수 없습니다** ("해당 모터를 참조로 사용하는 라인이 있습니다. 변경 후, 삭제할 수 있습니다."). 그 라인의 설정을 먼저 바꾸세요.

## 8. 자동 제어는 이렇게 동작합니다

제어 시작 후 라인마다 다음을 반복합니다.

1. **기존모터 읽기**: 사용 중인 기존모터에 0.5초 간격으로 RPM 을 묻고, 응답이 오면 목록의 숫자가 바뀝니다.
2. **신규모터 읽기**: 사용 중인 신규모터의 현재 상태(수동/자동, 동작/정지, RPM)를 0.5초 간격으로 읽습니다.
3. **목표 RPM 결정**
   - 수동 모드: 라인설정의 수동RPM값
   - 기존모터 모드: 참조 기존모터가 **정상**이면 그 RPM. 이상·대기·중지면 **제어하지 않고 기다림**(신규모터는 마지막 값 유지)
4. **신규모터 맞추기**: 신규모터가 수동 모드가 아니면 수동으로, 정지 중이면 동작으로, RPM 이 목표와 다르면 목표 RPM 으로 써넣습니다.
5. 접속이 끊기면 10초마다 다시 접속합니다.

**상태 판정**(5초마다): 마지막 응답 후 60초가 지나면 '이상' 입니다. 제어를 종료한 경우에도 60초 뒤 기존모터가 '이상' 으로 바뀌는 것은 정상 동작입니다.

## 10. 문제 해결

| 증상 | 확인할 것 |
|---|---|
| 1줄/2줄 점이 빨강 | 통신장치 전원, 랜선, IP/PORT(라인설정 창). `logs\motor_monitor.log` 에 "접속 실패" 기록 확인 |
| 3줄 점이 빨강 | 참조 기존모터가 '정상' 이 아님. 그 모터의 목록 상태 확인. 그동안 이 라인 신규모터는 제어되지 않음 |
| 기존모터가 계속 '대기' | 통신장치에 그 ID 가 없거나 ID 가 다름. 모터 ID 확인 |
| 기존모터가 '이상' | 60초 넘게 응답 없음 → 모터/통신장치 점검 |
| 신규모터가 계속 '대기' | 신규모터 통신장치에 그 ID 가 없거나 응답하지 않음. 모터 ID·통신장치 확인 |
| 참조 ID 목록이 비어 있음 | 선택한 라인에 기존모터가 등록되지 않음 → 그 라인에 기존모터 먼저 추가 |
| "모니터가 이미 실행중입니다." | 이미 실행 중인 창이 있음(작업 표시줄 확인) |

## 11. 장비 없이 시험하기 (시뮬레이터)

가상 통신장치를 띄워 화면과 제어 동작을 시험할 수 있습니다.

```
python -m motor_monitor.simulator --port 5020 --old 5:950,6:1000 --new 10,11
```
- 127.0.0.1:5020 에 기존모터 5번(950RPM), 6번(1000RPM), 신규모터 10번, 11번이 생깁니다.
- 라인설정 창에서 기존모터·신규모터 IP 를 `127.0.0.1`, PORT 를 `5020` 으로 저장하고, 해당 모터들을 추가한 뒤 제어를 시작합니다.
- 시뮬레이터 창에 신규모터로 써넣은 값(레지스터, 값)이 표시됩니다.
